# HUD

Telefon GPS'iyle çalışan, ön cama yansıtılan araç göstergesi (PWA). Tek sayfa, bağımlılık yok.

- Hız, pusula, yol adı ve hız limiti (OpenStreetMap), limit aşımı uyarısı
- Yolculuk süresi, mesafe, maks/ortalama hız
- Adres arama (Nominatim) ve sıradaki dönüş (OSRM)
- Ayna modu, gündüz/gece teması, ekran açık kalır
